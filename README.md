# Garaj Dubai Motors

Create a modern, responsive used-car marketplace web application called GARAJ.

The marketplace is focused on used cars imported from Dubai to Turkmenistan.

Design:

Clean, premium and minimalist interface inspired by Auto.ru.

White and light-grey backgrounds.

Red accent color.

Large car photographs.

Modern typography and simple navigation.

Brand name: GARAJ.

Tagline: Dubai Cars. Turkmenistan.

For the first version, create:

Public homepage with a car catalogue.

Car cards with photo, brand, model, year, mileage and price.

Filters for brand, year, price and vehicle condition.

Car details page with photo gallery and full specifications.

Admin dashboard to add, edit, publish and delete cars.

Image upload for each car.

Price breakdown: car price in USD, shipping cost, estimated repair cost and estimated total in USD and TMT.

A contact button that opens IMO chat with +99362141285.

Only the administrator adds and manages listings. Buyers do not need to register.

Use realistic sample cars for the initial visual prototype. Do not create fake backend functionality or claim that data is saved online yet. We will connect the application to our existing Supabase project later.

Make the application responsive for both desktop and mobile.
